## Dev Notes

### Constraints técnicas

- **`iconutil` workflow:** padrão Apple. `iconutil -c icns AppIcon.iconset` converte folder de 10 PNGs em `.icns`. Mas Xcode com `Assets.xcassets` faz isso automaticamente — só precisa do directory `AppIcon.appiconset` com PNGs + Contents.json. Não chamar `iconutil` manual.
- **`sips` para resize:** `sips -z 16 16 source.png --out icon_16x16.png` (height width). Loop em script bash gera todas sizes do 1024x1024 source.
- **`Assets.xcassets` JSON shape:** Apple documenta padrão `Contents.json` exato. Manter conformity ou Xcode reclama.
- **Version-in-bundle vs version-in-Cargo:** alinhar. Risk: Cargo `1.0.0` mas Info.plist `1.0` → CI AC-2 validation (Story 7.4) deve falhar. Test pre-tag.
- **CHANGELOG `[1.0.0]` date:** preencher na hora do PR — não cravar no draft (pode mover algumas semanas).
- **README screenshots:** Lorenzo decide se hotlinkar GitHub assets ou commitar PNGs. Decisão recomendada: committar (size pequeno, full repo standalone, e.g. para mirrors).
