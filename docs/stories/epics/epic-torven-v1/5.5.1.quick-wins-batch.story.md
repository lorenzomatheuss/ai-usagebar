## Contexto e Motivação

Wave 5 fechou 2026-06-07 com 4 issues identificados durante live smoke testing (real OpenRouter API key, $21.26 spend live). Issues documentados em `session_checkpoint.md` carry-forwards. Esta story bundle-os num único PR pra reduzir overhead (cada um < 1h, separar em 4 stories seria churn).

**Composição cravada:**

### ISSUE-A: SettingsView frame fixo corta Z.AI section
- **Arquivo:** `apple/Torven/Settings/SettingsView.swift:80`
- **Issue:** `.frame(width: 520, height: 360)` é hardcoded; com 4 vendor rows (Anthropic, OpenAI, OpenRouter, Z.AI) + Budget section, conteúdo excede 360pt e Z.AI section fica clipped.
- **Severity:** LOW (cosmético, mas visível imediatamente após abrir Settings)

### ISSUE-B: "gemini" residual no chart legend
- **Arquivos:**
  - Rust: `crates/torven-core/src/uniffi_exports.rs:228-232` (`VendorInfo { id: "gemini", ... }`)
  - Rust tests: `crates/torven-core/src/uniffi_exports.rs:1277-1284` (espera 5 vendors)
  - Swift: `apple/Torven/MainWindow/Charts/AggregatedSample.swift:50` (`chartVendorColorMapping` tem "gemini" entry)
  - Swift: `apple/Torven/MainWindow/Charts/AggregatedSample.swift:75` (`chartVendorDisplayName` retorna "Gemini")
- **Issue:** Gemini foi planejado v1.0 mas removido em alguma decisão (Wave 1-3?) sem cleanup completo. Aparece no chart legend como vendor cinza "reserved" mesmo sem nenhum sample real.
- **Severity:** MEDIUM (impacto UX maior — usuário vê "Gemini" no legend e pensa "esqueci de configurar?" mas o app não suporta).

### ISSUE-C: Chart vazio com 1 ponto (catmullRom degenera)
- **Arquivos:**
  - `apple/Torven/MainWindow/Charts/StackedAreaChart.swift:146` (`.interpolationMethod(.catmullRom)`)
  - `apple/Torven/MainWindow/Charts/MiniVendorChart.swift:174` (mesmo)
- **Issue:** Swift Charts `.catmullRom` requer ≥2 pontos pra calcular spline. Com 1 sample (1 dia de uso, ou range estreito), chart renderiza vazio.
- **Severity:** MEDIUM (encontrado durante primeira bench session — quando user vê pela primeira vez)

### MNT-001: `.disableAutocorrection(true)` deprecated
- **Arquivo:** `apple/Torven/Settings/VendorKeyRow.swift:66`
- **Issue:** macOS 14+ deprecou em favor de `.autocorrectionDisabled(true)`. Build mostra warning amarelo.
- **Severity:** LOW (warning only, sem runtime impact)

**Não-objetivo:** este NÃO é um refactor de SettingsView ou ChartViewModel. Cada fix é cirúrgico.

**Decisões cravadas:**
- **WAVE5.5-D1:** ISSUE-B = **remover** Gemini completamente (Rust + Swift + tests). NÃO add Gemini como vendor. Decisão de scope: post-v1.0 se demand surgir.
- **WAVE5.5-D2:** ISSUE-A = mudar pra `idealWidth/idealHeight + minHeight` (deixa SwiftUI calcular). Não cravar height novo.
- **WAVE5.5-D3:** ISSUE-C = fallback `samples.count < 2 ? .linear : .catmullRom` (preserva visual catmullRom quando dados ≥ 2 pts).
- **WAVE5.5-D4:** Bundle PR singular. Não criar 4 PRs separadas.

  - `get_vendor_list_has_canonical_order` order array trimmed to `["anthropic", "openai", "openrouter", "zai"]`.
  - `get_vendor_list_all_unconfigured_in_story_1_5` comment updated; assertion intent preserved.
