# Story 1.3 — Cleanup Linux-coupled code

**Story ID:** 1.3.cleanup-linux-code
**Status:** Done
**Epic:** Torven v1.0 — Pivot macOS native
**Estimated Effort:** S (3-5 horas)

---

## Story (User Story)

Como desenvolvedor do Torven, eu quero deletar todos os módulos acoplados ao Waybar/Linux (`waybar.rs`, `pango.rs`, `tooltip.rs`, `theme.rs`, `active.rs`, `widget/`, `bin/torven.rs`) e remover o `packaging/aur/`, para que o codebase fique limpo de código morto e `cargo build -p torven-core` compile sem imports de módulos inexistentes.

---

## Contexto e Motivação

Antes de mover código para `crates/torven-core/` (Story 1.4), é necessário remover o que não vai mais existir. Manter código morto aumenta ruído no diff das próximas stories, confunde o @dev na Story 1.4, e pode gerar falsos positivos em testes de snapshot.

Esta story é destructiva mas baixa risco: o `docs/architecture/preservation-map.md` já classificou exatamente o que deletar (bucket DELETE — 11 arquivos + `packaging/aur/`).

**Pode rodar em paralelo com Story 1.2** — as duas não tocam nos mesmos arquivos.

**Referência:** `docs/architecture/preservation-map.md#delete` e `docs/architecture/torven-v1-adr.md#4-cleanup-plan`.
